# ⚾ YA900

KBO 야구 팬들을 위한 웹 서비스로, 경기 일정 및 선수 기록 조회, 티켓 예매, 승부 예측, 야구 퀴즈 등의 기능을 제공합니다.

## 📅 프로젝트 기간
- 2026.09.20 ~ 2026.10.15
- 팀 프로젝트 (5명)

## 🛠 기술 스택
- **Frontend:** HTML, CSS, JavaScript, jQuery, JSP
- **Backend:** Java, Spring Legacy
- **Database:** Oracle
- **Server & Tools:** Apache Tomcat, Git, GitHub

## ✨ 주요 기능
- KBO 경기 일정 및 상세 정보 조회
- 선수 기록 및 구단 순위 조회
- 경기별 승부 예측
- 회원가입, 로그인 및 마이페이지
- 티켓 예매 및 야구 퀴즈

## 👨‍💻 담당 역할
- KBO 경기 일정 및 선수 데이터 크롤링
- JSON 데이터 파싱 및 데이터베이스 저장
- 경기 일정 및 상세 페이지 구현
- 선수 기록 및 구단 순위 페이지 구현
- 승부 예측 기능 구현
